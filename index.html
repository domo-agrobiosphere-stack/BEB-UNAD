01 / SOBRE NOSOTROS

Cultivando el futuro desde la raíz

Somos un semillero de investigación enfocado en cerrar la brecha entre la producción agrícola tradicional y la tecnología de vanguardia.

Nuestro enfoque combina Internet de las Cosas (IoT), machine learning y micología aplicada para desarrollar sistemas de cultivo inteligentes que maximicen la productividad mientras minimizan el impacto ambiental.

Trabajamos con Pleurotus ostreatus (orellanas) dentro del paquete tecnológico Agrobiosphere, un sistema de producción en ambientes controlados donde cada variable cuenta.

🌡️ Temperatura 20-30°C
💧 Humedad Relativa >85%
⚗️ pH del Sustrato 5.5 – 6.5
⚡ Conductividad Eléctrica Óptima
02 / PRODUCTO EN DESARROLLO

Monitoreo IoT de P. ostreatus

EN DESARROLLO # AGBIO-001

Relación entre variables ambientales y productividad del cultivo de orellanas en Agrobiosphere

Implementación de una red IoT para monitorear en tiempo real temperatura, humedad relativa, pH y conductividad eléctrica a nivel del tubular, correlacionando estos datos con la productividad mediante algoritmos de machine learning.

Investigador / Desarrollador

Yeison Jair Gaitán Orrego

Estudiante de Ingeniería de Sistemas — UNAD
Estudiante en Proyección · Semillero de Investigación

Objetivos Específicos

01

Cuantificar la productividad evaluando el desarrollo del micelio en los tubulares y la biomasa final en la cosecha.

02

Construir un modelo de análisis que identifique rangos óptimos de T°, humedad, pH y CE para maximizar rendimiento.

03

Determinar la distribución espacial más eficiente de tubulares mediante mapeo de variabilidad microclimática.

Hipótesis

El monitoreo continuo de las variables internas del tubular permitirá identificar los rangos óptimos requeridos en cada fase del cultivo. Al establecer la relación entre la configuración macro de Agrobiosphere y la respuesta interna de los tubulares, será posible ajustar los parámetros de manejo para maximizar la productividad y biomasa final.

03 / METODOLOGÍA

Tres fases, un sistema

FASE 01

Implementación de la Red IoT

Diseño e instalación de nodos de monitoreo con microcontroladores ESP32, sensores de temperatura, humedad relativa, y sondas de pH y conductividad eléctrica. Transmisión continua via protocolo MQTT a base de datos en la nube.

ESP32 Sensores T°/HR Sondas pH/CE MQTT Cloud DB
FASE 02

Levantamiento de Datos Operativos

Monitoreo continuo de al menos un ciclo completo de producción. Registro automatizado de variables ambientales combinado con registros manuales de productividad: peso de cosecha, tiempo de aparición de primordios y número de cuerpos fructíferos por tubular.

Ciclo completo Datos en tiempo real Geolocalización tubular Registro biomasa
FASE 03

Correlación y Modelado

Análisis estadístico descriptivo, correlación de variables y aplicación de algoritmos de machine learning para construir un modelo predictivo de rendimiento. Mapeo de variabilidad espacial para optimizar distribución de tubulares.

Machine Learning Modelo predictivo Análisis espacial Optimización
04 / STACK TECNOLÓGICO

La red detrás del cultivo

Hardware IoT

Microcontroladores ESP32 con sensores de alta precisión para temperatura, humedad, pH y conductividad eléctrica integrados en cada nodo.

ESP32 DHT22 pH Meter TDS/CE

Comunicación

Protocolo MQTT para transmisión de datos en tiempo real desde los nodos hacia la infraestructura cloud con baja latencia.

MQTT WiFi JSON Real-time

Cloud & Datos

Base de datos centralizada en la nube para almacenamiento persistente, visualización de dashboards y análisis histórico continuo.

Cloud DB Dashboards API REST Storage

Machine Learning

Algoritmos de aprendizaje automático para identificar patrones no lineales y construir modelos predictivos de rendimiento del cultivo.

Python Predictivo Correlación Optimización
